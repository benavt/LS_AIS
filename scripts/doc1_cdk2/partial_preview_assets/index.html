Model counts by generation method

Geometry uses all accepted full-construct chains A/B/C and the validated 4,096-dimensional all-pair sketch. UMAP and the clustering views shown above are saved outputs from the accepted seed-42 run. HDBSCAN EOM is a diagnostic alternate; unassigned models remain unassigned. No energy values appear in this partial preview.

PCA fits 50 components to every accepted model's 4,096-dimensional all-pair sketch; the first two components are plotted. t-SNE fits all models from those 50 PCA coordinates (perplexity 30, seed 42). The Cα median map uses a frozen uniform sample of 5,000 models per target; the population variance map uses every accepted model. Both maps retain all A/B/C residues and mark chain boundaries.
